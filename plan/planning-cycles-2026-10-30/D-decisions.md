# Décisions — cycles et codes remplaçants

Numéros jamais réattribués. A : questions. B : réponses (utilisateur, ou par
défaut réversible). C : révisions datées.

## B. Réponses

Données par l'utilisateur le 2026-10-30 (questionnaire) :

- **D1. Besoins par code** : GARDÉS. Le moteur doit « jouer avec les outils »
  pour les tenir, et laisser vide quand c'est impossible.
- **D2. Minimum par cycle** : matin, soir ET nuit, à tenir « de manière plus
  dure ». Le middle est un shift à part (voir D11, D12).
- **D3. Place impossible** : tout ce qui peut être placé l'est ; le reste est
  laissé vide avec « je ne peux pas faire de choix », à l'équipe de trouver un
  extra. Le moteur ne pose rien d'inventé.
- **D4. Relève** : le chevauchement est mieux, pas obligatoire : un bonus.

Par défaut (réversibles) :

- **D5. Code exact d'abord** : un remplaçant coûte un peu plus que le code
  imposé, pour que le moteur ne change de code que s'il le faut.
- **D6. Un shift posé compte pour le besoin de son cycle** (même poste, même
  jour), code exact rattaché en premier.
- **D7. Minimum par cycle au niveau d'une place nécessaire** (P1) : avant les
  heures dues, le 6e jour et le confort ; jamais avant la loi. Le maximum reste
  souple.
- **D8. Coupure de 11 h jamais en automatique** (D16 du plan précédent) : un
  remplaçant ne la passe pas non plus.
- **D9. Apprentis et stagiaires** : jamais comptés dans le minimum par cycle ;
  « soutien jamais seul » inchangé.
- **D10. Trou entre cycles** : signalé et évité par le moteur quand c'est
  possible (coût), jamais une règle qui bloque.
- **D11 (utilisateur)** : « il ne compte pas mais il est quand même là ». Un
  middle ne compte dans AUCUN minimum par cycle, mais il compte comme une
  présence pour les trous entre équipes (étape 6).
- **D12 (utilisateur)** : non, un remplaçant vient du même cycle seulement ;
  un middle ne remplace qu'un middle.
- **D13 (utilisateur)** : le métier d'abord. Ordre : titulaire avec le code
  imposé, titulaire avec un autre code du même cycle, dépannage (adjointe,
  superviseur, extra) avec le code imposé, dépannage avec un autre code, puis
  place vide avec message. Donc coût d'un remplaçant < part fixe d'un
  dépannage.
- **D14 (utilisateur)** : une adjointe sur son propre poste ne compte pas dans
  les minimums de l'accueil ; elle compte quand elle est posée sur la
  Réception ou le Club.
- **D15 (par défaut, constat du 2026-10-30)** : la Réception et le Club n'ont
  aucun code de nuit ; le minimum de NUIT compte donc les postes qui ont des
  codes de nuit (Veille de nuit), le matin et le soir gardent les postes
  cochés « présence ». Aucun code horaire ajouté ni modifié.

- **D16 (utilisateur)** : option A pour le coût d'un remplaçant :
  `POIDS_REMPLACANT` ≈ 2 000, sous la part fixe d'un dépannage ; les paliers
  actuels restent ; le confort peut rarement faire préférer un code voisin.
