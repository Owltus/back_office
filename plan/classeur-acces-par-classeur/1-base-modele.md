# Étape 1 — Modèle : accès pour tous, exceptions, niveau effectif

## Objectif

Poser en base de quoi calculer, pour l'utilisateur connecté, son **niveau
effectif** sur un classeur (`aucun`, `lecture`, `ecriture`, `gestion`), selon
les règles de `00-INDEX.md`.

## Fichier(s) impacté(s)

- `supabase/classeur_acces_2026-09-28.sql` (nouveau, sections 1 et 2)
- `supabase/classeur_2026-09-25.sql` (autorité : même bloc, nouvelle section)

## Travail à réaliser

### 1. Colonne « accès pour tous »

```sql
alter table public.classeur_classeurs
  add column if not exists acces_tous text not null default 'lecture'
  check (acces_tous in ('aucun', 'lecture', 'ecriture'));
```

Le `default 'lecture'` fait la bascule des 3 classeurs existants
(décision utilisateur : « à défaut, tous en lecture »).

### 2. Table des exceptions

```sql
create table if not exists public.classeur_acces (
  id           bigint generated by default as identity primary key,
  classeur_id  bigint not null references public.classeur_classeurs(id) on delete cascade,
  user_id      uuid   not null references public.profiles(id) on delete cascade,
  niveau       text   not null check (niveau in ('aucun', 'lecture', 'ecriture')),
  created_at   timestamptz not null default now(),
  updated_at   timestamptz not null default now(),
  created_by   uuid references public.profiles(id) on delete set null,
  unique (classeur_id, user_id)
);
create index if not exists classeur_acces_user_idx on public.classeur_acces (user_id);
```

`on delete cascade` sur `user_id` : un compte supprimé n'a plus d'exception.

### 3. Le niveau effectif (une seule fonction, source de vérité)

```sql
create or replace function private.classeur_niveau(p_classeur_id bigint)
returns text language sql stable security definer set search_path = ''
as $$
  with page as (select private.get_page_level('classeur') as n),
  droit as (
    select coalesce(
      (select a.niveau from public.classeur_acces a
        where a.classeur_id = c.id and a.user_id = auth.uid()),
      case when c.created_by = auth.uid() then 'ecriture' end,
      c.acces_tous) as n
    from public.classeur_classeurs c where c.id = p_classeur_id
  )
  select case
    when (select n from page) is null then 'aucun'
    when (select n from page) = 'gestion' then 'gestion'
    when not exists (select 1 from droit) then 'aucun'
    when (select n from droit) = 'aucun' then 'aucun'
    when (select n from page) = 'lecture' then 'lecture'      -- plafond
    else (select n from droit)                                  -- page ecriture
  end;
$$;
```

Aides dérivées (definer, `private`, fermées à `anon`/PUBLIC) :

- `private.classeur_lecture_ok(id)` → niveau ≠ `aucun` ;
- `private.classeur_write_ok(id)` → **réécrite** : niveau ∈ (`ecriture`,
  `gestion`). Même nom et même signature : les 12 policies d'écriture
  existantes suivent sans être touchées ;
- `private.classeur_chapter_read_ok(chapter_id)` → lecture du classeur parent ;
- `private.classeur_chapter_write_ok(chapter_id)` → inchangée (appelle
  `classeur_write_ok`) ;
- `private.classeur_gestion_ok()` → page = `gestion` (admin compris).

⚠ Garde de niveau écrite `is distinct from` / comparaisons explicites, jamais
`<> 'gestion'` (NULL passe) — règle du projet.

  qualifié.
